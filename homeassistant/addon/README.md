# Eisfach Home Assistant Add-on

Dieses Repository enthält das **Eisfach Inventar Server** Add-on für Home Assistant.

## Installation

1. Füge dieses Repository als Add-on-Repository in Home Assistant hinzu:
   - Gehe zu **Einstellungen** ➡️ **Add-ons** ➡️ **Add-on-Store** ➡️ **⋮** ➡️ **Repositories**.
   - Füge die URL deines GitHub-Repositories hinzu.
2. Installiere das **Eisfach Inventar Server** Add-on.
3. Starte das Add-on.
