# Home Assistant Add-on: Eisfach

Eisfach ist ein modernes, SQLite-basiertes Inventarsystem für Tiefkühlschränke, Vorratsräume und Lager.

## Installation als Add-on über GitHub

1. Füge dieses Repository (`https://github.com/Korbinian0/Eisfach`) als Add-on-Repository in Home Assistant hinzu:
   - Gehe in Home Assistant zu **Einstellungen** ➡️ **Add-ons** ➡️ **Add-on-Store** ➡️ **⋮ (Menü oben rechts)** ➡️ **Repositories**.
   - Füge `https://github.com/Korbinian0/Eisfach` hinzu.
2. Aktualisiere die Ansicht und installiere das **Eisfach Inventar Server** Add-on.
3. Starte das Add-on. Das Standard-Admin-Konto ist `admin` / `admin`.
